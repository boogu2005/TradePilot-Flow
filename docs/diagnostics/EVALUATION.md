## 结论边界

- Agent 对跨订单、成交、持仓和日志的证据冲突有价值，可以生成可审计计划并把高风险写操作停在审批边界。
- 心跳、重连、常规 REST 恢复、风险校验、退出管理和明确状态核对仍由确定性 Workflow 处理。
- 当前结果证明模拟闭环与防重复控制可运行，不代表真实交易所延迟、限频、断网和供应商模型行为已经完成生产验证。
- 真实接入前需为允许的业务动作注册交易所执行适配器，并在沙盒账户完成超时后查单、幂等重放和后置条件验证。
